# QA Report Template

Generate reports following this exact structure.

## Template

```markdown
# QA Report: {Flow Name}

**URL:** {base URL}
**Date:** {YYYY-MM-DD HH:MM}
**Steps Executed:** {N}
**Duration:** {time}
**Result:** PASS / FAIL / ISSUES FOUND

---

## Summary

{1-3 sentence overview of findings}

**Critical Issues:** {count}
**Warnings:** {count}
**Passed Steps:** {count}/{total}

---

## Step-by-Step Results

### Step 1: {Action Description}
**Action:** {what was done}
**URL:** {current URL}
**Status:** PASS / FAIL / WARNING

![Step 1 Screenshot](./{screenshot-filename})

**Observations:**
- {observation 1}
- {observation 2}

**Console Errors:** {none / list}
**Network Errors:** {none / list}

---

{repeat for each step}

---

## Console Error Summary

| # | Level | Message | Source | Step |
|---|-------|---------|--------|------|
| 1 | error | {msg}   | {file} | {N}  |

## Network Error Summary

| # | Status | Method | URL | Step |
|---|--------|--------|-----|------|
| 1 | {4xx}  | GET    | {url} | {N} |

## Performance Notes

- Page load time: {if captured}
- Largest Contentful Paint: {if captured}
- Notable slow requests: {list}

## Recommended Fixes

1. **[CRITICAL]** {fix description}
2. **[WARNING]** {fix description}
3. **[SUGGESTION]** {improvement idea}

---

*Generated by Manual QA Machine*
```

## Severity Levels

- **CRITICAL** — Broken functionality, crashes, data loss, security issues
- **WARNING** — Degraded UX, console errors, slow loads, missing elements
- **SUGGESTION** — Minor improvements, accessibility, polish

## Screenshot Embedding

Reference screenshots relative to the report file:
```markdown
![Step 1 Screenshot](./01-click-signup-button.png)
```

Store screenshots in the same directory as the report file.

## Multiple Viewport Reports

When testing responsive layouts, add a viewport section header:

```markdown
## Desktop (1920x1080)
{steps}

## Tablet (768x1024)
{steps}

## Mobile (375x667)
{steps}
```
